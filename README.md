# สมาร์ตมันนี่ · ผู้ช่วยวางแผนการเงิน

เว็บแอปภาษาไทยสำหรับวางแผนรายได้ จัดสรรเงิน บันทึกรายจ่าย และติดตามเป้าหมายเงินทุน พัฒนาด้วย React + Vite

## ความสามารถ
- ภาพรวมรายได้ เงินลงทุน รายจ่าย และเป้าหมายรายเดือน
- เก็บรายได้แยกเดือนด้วย `incomeByMonth` และเลือกเดือนที่ต้องการดูได้
- จัดสรรรายได้เป็นหมวด พร้อมแจ้งเตือนเมื่อสัดส่วนไม่ครบ 100%
- บันทึกรายจ่ายแยกหมวดและวันที่ พร้อมลบ/เลิกทำ
- เปรียบเทียบยอดใช้จริงกับงบจัดสรรของแต่ละหมวด
- คำนวณเป้าหมายเงินทุนโดยไม่สมมติผลตอบแทน
- ส่งออกและนำเข้าข้อมูล JSON พร้อมตรวจสอบโครงสร้างก่อนเขียนทับ
- ธีมสว่าง/มืด/ตามการตั้งค่าระบบ
- บันทึกข้อมูลใน LocalStorage ของเบราว์เซอร์
- รองรับหน้าจอมือถือและคอมพิวเตอร์ พร้อมเมนูล่างบนมือถือ

## เริ่มใช้งาน
ต้องติดตั้ง Node.js 20 หรือรุ่น LTS ที่รองรับก่อน

```bash
npm install
npm run dev
```

## ตรวจสอบและ build

```bash
npm run build
npm run preview
```

ไฟล์สำหรับเผยแพร่จะอยู่ใน `dist/` โดยแยก Recharts และ Lucide เป็น chunk ต่างหาก

## เผยแพร่ผ่าน GitHub Pages
1. สร้าง GitHub Repository ชื่อ `smart-money-planner`
2. อัปโหลดไฟล์ทั้งหมดในโปรเจกต์ (รวม `.github/workflows/deploy.yml`)
3. ไปที่ **Settings → Pages** แล้วเลือก **GitHub Actions** ในส่วน Build and deployment
4. Push ไปยัง branch `main` หรือกด workflow ด้วยตนเองในแท็บ Actions
5. เมื่อ workflow สำเร็จ เว็บไซต์จะเผยแพร่ที่ `https://ชื่อผู้ใช้.github.io/smart-money-planner/`

ตั้งค่า `base: './'` ไว้แล้วเพื่อรองรับ path ของ GitHub Pages

## ข้อจำกัดและความปลอดภัย
- ข้อมูลเก็บใน LocalStorage ของเบราว์เซอร์เครื่องนั้น ไม่ได้ซิงก์ข้ามอุปกรณ์
- ยังไม่มีระบบสมาชิกหรือฐานข้อมูลบนเซิร์ฟเวอร์ และไม่มีการเชื่อมบัญชีธนาคาร
- ควรส่งออกไฟล์สำรองเป็นระยะ และเก็บไฟล์ JSON ไว้ในที่ปลอดภัย
- การจัดสรรเป็นเพียงเครื่องมือวางแผน ไม่ใช่คำแนะนำการลงทุนเฉพาะบุคคล
