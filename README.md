# Smart Money Planner

เว็บแอปวางแผนรายได้ การจัดสรรเงิน บันทึกรายจ่าย และเป้าหมายเงินทุน พัฒนาด้วย React + Vite

## คุณสมบัติ
- Dashboard สรุปรายได้ เงินลงทุน รายจ่าย และเป้าหมาย
- ปรับสัดส่วนจัดสรรรายได้ต่อเดือนได้
- บันทึกรายจ่ายพร้อมวันที่ และลบรายการได้
- กราฟสัดส่วนการจัดสรรและรายจ่ายรายเดือน
- คำนวณเป้าหมายเงินทุนจากเงินลงทุนรายเดือน (ไม่รวมผลตอบแทน)
- ส่งออกข้อมูลสำรองเป็น JSON
- บันทึกข้อมูลใน LocalStorage ของเบราว์เซอร์
- รองรับมือถือและคอมพิวเตอร์

## เริ่มใช้งานในเครื่อง
ต้องติดตั้ง Node.js รุ่น LTS ก่อน

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน Terminal

## ตรวจสอบก่อนเผยแพร่

```bash
npm run build
```

ไฟล์เว็บไซต์สำหรับเผยแพร่จะอยู่ในโฟลเดอร์ `dist/`

## อัปโหลดขึ้น GitHub
1. สร้าง Repository ใหม่บน GitHub ชื่อ `smart-money-planner`
2. แตกไฟล์ ZIP นี้
3. เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรัน:

```bash
git init
git add .
git commit -m "Initial Smart Money Planner app"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/smart-money-planner.git
git push -u origin main
```

แทน `YOUR-USERNAME` ด้วยชื่อบัญชี GitHub ของคุณ

## เผยแพร่เป็นเว็บไซต์ด้วย GitHub Pages
โปรเจกต์นี้ใช้ Vite; หากต้องการใช้ GitHub Pages ต้องตั้งค่า `base` ใน `vite.config.js` ให้ตรงกับชื่อ repository และตั้ง workflow สำหรับ build/deploy หรือใช้บริการอย่าง Vercel/Netlify ที่เชื่อมกับ GitHub ได้โดยตรง

## ข้อจำกัดและความปลอดภัย
- ข้อมูลเก็บใน LocalStorage ของเบราว์เซอร์เครื่องนั้น ไม่ได้ซิงก์ข้ามอุปกรณ์
- ยังไม่มีระบบสมัครสมาชิกหรือฐานข้อมูลบนเซิร์ฟเวอร์
- ไม่มีการเชื่อมบัญชีธนาคาร
- ตัวเลขการจัดสรรเป็นแนวทางที่ผู้ใช้กำหนด ไม่ใช่คำแนะนำการลงทุนเฉพาะบุคคล
- ก่อนใช้กับเงินจริง ควรตรวจสอบตัวเลขและปรับตามหนี้สิน ค่าใช้จ่าย ภาระครอบครัว และความเสี่ยงที่ยอมรับได้
